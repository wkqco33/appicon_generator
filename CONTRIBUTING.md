# Contributing

## Before opening a pull request

1. Create a focused branch from the default branch.
2. Add or update tests before changing behavior.
3. Run `cargo fmt --all`, `cargo clippy --all-targets --all-features -- -D warnings`, and `cargo test --all-targets`.
4. Update the README when user-facing behavior changes.

Keep commits focused and do not include generated files, credentials, personal data, or release archives. Pull requests should explain the problem, the chosen approach, and how it was tested.
